## About this site

Static site hosted on GitHub Pages. No build step, no dependencies.

```
index.html               markup
assets/style.css         design system + layout (dark/light themes)
assets/main.js           theme toggle, scroll-spy, reveal animations
profile.jpg              headshot
Arman-Dabiri-Resume.pdf  downloadable resume
.nojekyll                tells GitHub Pages to serve files as-is (no Jekyll build)
```

Deployed straight from the default branch — GitHub Pages serves `index.html` at the repo root.
All asset paths are relative, so no base-URL configuration is needed.

To preview locally:

```bash
python3 -m http.server 8080
```
